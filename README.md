# CINEMA X

CINEMA X is an interactive, modern movie browsing web application designed to give users a seamless cinematic experience from the comfort of their screens. Using real-time data from The Movie Database (TMDB) API, CINEMA X allows users to explore trending, popular, and top-rated films with visually appealing layouts and dynamic features. The platform focuses on providing a smooth user journey—from discovering new titles to creating a personalized Watchlist—all supported by a responsive interface that adjusts beautifully across devices.

The goal of CINEMA X is to combine functionality and design to create an engaging entertainment hub. Users can easily register or log in, browse movies by category, and access detailed information such as ratings, descriptions, and trailers. Every interaction is designed to feel natural and intuitive, making CINEMA X not just a project, but a complete web experience that demonstrates strong teamwork, front-end development skills, and real-world API integration.

---

## Features

- **Sign In / Sign Up Forms**  
  Built with Firebase and Local Storage for smooth authentication and user data handling.

- **Home Page**  
  Displays dynamic content such as automatic sliders and top-rated movie sections.

- **Library Page**  
  Fetches movie data dynamically using the TMDB API and organizes it into categories such as "Top Rated" and "Most Popular."

- **Watchlist Page**  
  Allows users to add and remove movies from their personalized Watchlist.

- **Single Movie View**  
  Displays detailed information for each selected movie, including title, overview, trailer, and release details.

- **Responsive Design**  
  Fully responsive and optimized for desktop, tablet, and mobile screens.

- **Modern Styling**  
  Styled with CSS, Bootstrap, and custom gradients to match a cinematic theme.
